# Hiking browser in Carta Main Edit

Open **Views** and check several groups to combine their hikes into one list. Available groups include My hikes, Completed, To do + partial, recorded activities, reference routes, peaks, visit history and named saved lists. Membership combines by union. Saved-list membership never asserts a personal completion status. **Solo** selects just that group; **Done** closes the chooser. An empty selection deliberately shows no hikes.

Each selected group has its own route color, checkbox and **Show/Hide** control. Click a selected color swatch to cycle the palette. New groups prefer an unused color. Up to 32 groups can be selected; the 12-color palette repeats after all colors are used. Colors, group order, visibility and selections persist as UI preferences, separately from the personal database. Existing single-view settings migrate automatically.

The first three selected groups also have tinted legend buttons above Search; click a legend button to hide/show that group's map overlays. The Views heading reports total selections and map-visible groups when several are selected. Further groups remain accessible in the chooser. Hidden groups remain browsable, with subdued tints. Every matching group contributes a colored stripe to the hike card. Its background and route use the first matching map-visible group's tint; if all matches are hidden, its card uses the first selected match and the route stays hidden. Overlapping groups and explicit route/recording pairs do not duplicate the hike card or route overlay. Recorded activities includes linked route/recording pairs as one card.

Search narrows the combined list. Fractional trackpad scrolling, clipped partial rows and a draggable proportional scrollbar retain stable row identities. Clicking a hike frames its full source route. **Show results** displays routes from map-visible selected groups; **Show selected** isolates the chosen hike while respecting group visibility. **Fit results** enables results display and frames only visible group geometry. **Fit route** frames the selected hike. Changing group membership/visibility does not move the camera until a fit action is used.

Tools contains editing, archive, original GPX export, nearby peaks, Reload data, geographic names, peak goals and downloaded terrain management. Progress remains textual on each card and explicit in the detail controls, independent of group route colors. Completion controls retain guarded save and undo. Keyboard chooser controls: arrows/Home/End move focus, Space/Enter toggles selection, M toggles map visibility, C cycles a selected tint, Shift+Enter selects Solo, Escape closes.

Results prepare one missing original per frame with selected geometry first, then return to idle. The selected route reserves drawing budget and paints last, so other routes sharing the same path cannot obscure its tint. Colored strokes have dark edges for contrast over relief. Missing/damaged assets and the retained 64-entry/32 MiB cache limits become terminal display states until Reload data, preserving durable originals. Dense overlays retain the 6,000-segment budget. This slice adds no map downloads, imports, completion guesses or personal schema changes.

Implementation reuses unchanged kit_ui 0.11.2 scrolling, existing renderer clipping, theme/font and idle gate. The app-owned history_views module contains group membership, palette and UI preference serialization. No shared API or version changes.
